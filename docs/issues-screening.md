## 🟢 第一梯队 — 非常适合新手（建议优先尝试）

这些 Issue 定位清晰、改动小、好验证，适合作为首次 PR 练手。

| # | 标题 | 难度 | 关键点 |
|---|------|------|--------|
| **#862** | 在快进状态下结束游戏，快进图标仍处于"按下"状态 | ★☆☆ | `end;` 后未重置按钮的 pressed class。用户自述"只影响样式，功能正常"。 |
| **#769** | 获取玩家名字时，长度无限制 | ★☆☆ | `getUserInput` 缺校验，加 `maxLength` 即可。 |
| **#855** | 建议加入字符串长度限制（getUserInput） | ★☆☆ | 与 #769 同类，可一并修复。 |
| **#752** | 播放不存在的效果音时，自动播放失效且无报错 | ★★☆ | 大概率是音频加载失败未 catch，导致 `isAuto` 流程断裂。加 try-catch 或 404 检查。 |
| **#866** | 回放界面（Backlog）点击不同语音会混合播放 | ★★☆ | 播放新语音前未 `stop()` 旧音频，加一行即可。 |

## 📌 推荐上手顺序

```
#862  →  #769 + #855  →  #866  →  #752
  1         2                3        4
```

**理由**：
1. **#862** 最安全，纯 UI 样式重置，不会引入回归。
2. **#769 + #855** 同源问题，一次 PR 解决两 Issue，性价比高。
3. **#866** Backlog 音频交互，逻辑独立，验证简单。
4. **#752** 涉及错误处理，需要读一下 `playEffect` 相关代码。

## 提 PR 前 Checklist

- [ ] Issue 是否仍处于 open 状态（关闭时间：<https://github.com/OpenWebGAL/WebGAL/issues>）
- [ ] 复现环境与 Issue 描述一致
- [ ] 修复后写明复现步骤与验证方法
- [ ] 提交信息格式：`fix: 简述 (close #862)`
- [ ] 不夹带 `.claude/`、个人配置等私货
- [ ] `.gitignore` 改动单独提交，不与功能修复混在一起
