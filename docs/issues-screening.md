## 提 PR 前 Checklist

- [ ] Issue 是否仍处于 open 状态（关闭时间：<https://github.com/OpenWebGAL/WebGAL/issues>）
- [ ] **再次确认无新开 PR**（搜索 `is:pr #<num>`）
- [ ] 复现环境与 Issue 描述一致
- [ ] 修复后写明复现步骤与验证方法
- [ ] 提交信息格式：`fix: 简述 (close #<num>)`
- [ ] 不夹带 `.claude/`、个人配置等私货
- [ ] `.gitignore` 改动单独提交，不与功能修复混在一起
- [ ] **PR base 是 `dev`，不是 `main`**（见 [workflow.md](./workflow.md)）
